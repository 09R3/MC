# Photos

Drop images here to use in project/app cards or anywhere else on the site.

Reference them from `js/data.js` like:

```js
image: "photos/your-file.jpg"
```

Keep filenames lowercase with dashes (e.g. `my-project-screenshot.jpg`) and
images reasonably sized for the web (under ~500KB, resized to roughly
1200px wide is plenty for card thumbnails).
